# P509 save format20

Status: verified24October2026; same-build native WASAPI and complete compatible suite PASS.

This candidate saves P509 only with one trusted original narrator program5 at command index3, an internal800ms conditional wait, with narration ready and ordinary SKY1/SKY2 play. Other legitimate narrator indices remain outside this contract. Startup, repeat narration, button/action work, hovering, foreground sound, image staging, phase3/failure exit and success transitions are excluded. P509 retains pending narrator work during ordinary play; the loader preserves it rather than canceling it or replaying startup.

The4540-byte stream contains8bytes ASVM/version20,11little-endian header words,19sprites×27words,608runner words and one checksum word. Starting with2166136261, checksum updates `(hash XOR word)*16777619` for every payload word. It detects corruption and is not authentication.

Header0..10: place509, completed count, script clock, previous place(-1sentinel allowed), loop sound(-1/0), loop enabled(0), last sound timestamp, active ambient(0), comet frame1..12, previous comet frame0..12, displayed image1/2. Original program2 disables the ambient loop; this contract does not invent an active loop in ordinary P509. Mixer Music volume is a current user setting and loading leaves it unchanged.

Image1/2 means original SKY1/SKY2,640×320 copied at0,0 over a freshly loaded full HYP scene. The lower scene/control is retained. SKY3 is a genuine queued-failure image and is excluded from saved boundaries; it is nevertheless preflighted for future original-script execution. Names are SKY1/SKY2/SKY3, without an extension or `_B` suffix.

Each27-word sprite record preserves visibility, selected frame, storedXY, renderedXY, auto-frame/move, frame/move epochs, standard-motion, runtime deltas, orbit flag/sides, frame range, click-enabled,3frame parameters and5move parameters. All19sprites own their frames. Unused orbit/planet private fields must remain original defaults. The six classification buttons match local7's selection at admitted boundaries. Presence flags govern original target visibility in each sky; the phase/remaining-target checks exclude transitions that have already queued completion.

StoredXY475,45 stays fixed; selected frame, renderedXY, reversed runtimeDX/DY and independent epochs are restored. Conservative original-derived bounds areX448..589,Y-1..66,DX±2,DY±1. This is range validation, not an exhaustive proof of every accepted dynamic combination's reachability. No clock/position snapping or artificial phase relation is imposed.

Runner0..604 preserves100global and100local values plus width/known metadata, RNG600, original program-loaded-at601, conditional lastTrue602 and dormant variant603/604. P509 declares17locals; the other historical values remain unmodified with original unknown metadata. Globals retain the established original width0/6 rules. Runner605..607 is trusted program5, command index3, pending since. These are data identifiers and epochs; no code is serialized. The code identity is compared against the original25-command template including opcode, arguments, delay and text, under a P509/full-HYP caller binding.

The narrator does not have a simple800ms recurrence: opcode41 appends a new program5/index0 with original loadedAt, deferred until the next scheduler pass. Internal conditional waits then rearm since at the actual execution time. Saved601/602/607 and next-pass ordering are preserved, including a boundary already due when loaded. Script and sprite epochs use the engine's signed modular32-bit comparisons; supported ages remain within that half-range.

Preflight checks the full713948-byte HYP(FNV3651436523) and all205878-byte SKY1/2/3 assets(FNV1362d518/f33e47a0/8da73602), parses the profile, validates sprite/state/phase/image/clock data, and validates runner import on a temporary configured runner. Then loadPlace(509,false,true) rebuilds live handlers/targets, the608words are imported onto that configured live runner, sprite/clock/audio/comet fields are restored and the selected background is displayed. The prepared runner is never assigned over the live one. Host I/O changing after preflight is outside the atomic guarantee.

Native tests invoke the actual isolated engine. Roundtrips compare bytes, the immediate restored clock, runner/pending state, every sprite record and480-row screen/background hashes after2000ms of successors at10ms ticks. This coarse outcome schedule is a diagnostic test condition, not a claim about manual play timing. Foreground voice ends naturally in a separate native case. Disabled Music state must remain stopped and current Music volume must remain unchanged. Full malformed-byte and checksummed invalid-state rejection tests cover current audio, queues, clock and pending/movie pixel sentinels.
