# P521 save format19

Status: verified23October2026; same-build native WASAPI and complete compatible suite PASS.

The format covers settled P521 script boundaries, including active400ms sprite12 animation and retained hidden histories after any of the five controls. Queued script work, button pulses, hover, foreground audio, movie frames, pending images and the transient ROCKS_B display are excluded. This is actual staged engine code; no original runtime execution is claimed.

The stream is5392bytes:8bytes `ASVM`/little-endian version19;11little-endian header words;27sprites×27words;605persistent runner words; one checksum word. The checksum starts2166136261 and applies `(hash XOR word)*16777619` to each payload word. It is a corruption check, not authentication.

Header words0..10 are place521, completed count, script clock, previous place(signed sentinel-1 allowed), ambient loop sound(-1/0), loop enabled(1), last sound timestamp, ambient active(0/1), comet frame1..12, previous comet frame0..12, and image identity0/1. Image0 is original HYP background; image1 is EARTH_B at0,0. EARTH_B matches the embedded320-row bitmap byte-for-byte, but its displayed name remains state. The full HYP scene is loaded before the320-row overlay so the lower scene/control remains intact.

Each sprite record preserves visibility, selected frame, storedXY, renderedXY, auto-frame/move flags, frame/move epochs, standard-motion flag, runtime deltas, orbit flag/sides, frame range, click-enabled and the original3frame/5move parameter words. Inactive orbit/planet fields must retain original defaults. Clone positions/flags remain their own; only frame resources are inherited.

The605runner words preserve all100global and100local values and width/known metadata, RNG, loaded-at clock, and dormant variant fields. P521 declares no locals: their known flags/widths are zero while historical values remain unmodified. Global known flags are1; width0/6 is permitted for indices0..2 and0for the rest, per original-resource inventory. There is no serialized code or pending-program continuation.

The validator recreates immutable sprite fields from the original scene, then admits original-control changes. Sprite13 is settled at15,251/frame2. Sprite12 retains its active400ms frame and epoch. Sprite11 is untouched or retains stopped20ms history; image1 requires that stopped history. With image1 all ten fragments are hidden, stopped and retain their literal wrap velocities/parameters, independent selected frames and epochs. Render coordinates use bounds derived from the original OLD-rectangle wrap algorithm, including a one-step overshoot; they are not snapped to stored coordinates or reset on repeated choice5. This is a conservative range contract, not an exhaustive proof that every accepted combination is reachable.

Loading checks the complete original HYP717441bytes/FNV1a1101702870 and both original205878-byte image resources(EARTH_B5c98bffb, ROCKS_B2f1f989d), parses the profile, checks state and sprite records, and decodes/converts both image assets before mutation. Then loadPlace(521,false,true) recreates live bindings, runner import preserves them, sprite/clock/audio/comet/image state is installed and redrawn. Preflight protects malformed payloads and known immutable assets; host I/O changes between preflight and installation are outside this contract.

Tests use actual engine methods in an isolated build with SDLdummy audio/video. They compare byte streams, immediate restored clocks, full480-row screen/background pixels, all sprite records and runner state after successor ticks. First-success audio912 uses host elapsed time in its diagnostic completion field. P521 unlocks in the same script pass and the test then sends a separate exit click at the controlled script clock. First success, repeat success and unsolved exit therefore compare exact clocks and full state after reaching388, including runner loaded-at word601; no timing or pixel normalization is applied. No manual playthrough or official WASAPI/full-suite claim is implied by candidate diagnostics.
